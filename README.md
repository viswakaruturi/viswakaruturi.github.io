## Deploy
1. Back up your GitHub repository.
2. Extract this ZIP and upload its **contents** to the root of the GitHub Pages repository `viswakaruturi.github.io` (do not upload the enclosing folder).
3. Preserve the `CNAME` file (`viswakaruturi.com`).
4. In GitHub Settings → Pages, use the appropriate main-branch root deployment and confirm your custom domain and HTTPS.
5. Verify all four page links, three resume links, and external links.
